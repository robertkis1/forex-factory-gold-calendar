How the system works

  1. GitHub Actions: scheduled hourly at minute 17 UTC (GitHub can delay or skip runs).
  2. Python updater: downloads Forex Factory's current-week ICS, filters US high/medium events and writes the calendar file.
  3. GitHub Pages: republishes the ICS when a commit changes it.
  4. Apple Calendar: checks the subscribed feed on your device's 15-minute setting.
  5. This monitor: checks actual GitHub workflow results and the publicly published ICS, not merely the schedule.
